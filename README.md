### Personal Blog Website
A modern and responsive personal blog website built to share thoughts, projects, experiences, and ideas in a clean and engaging way.

## 🌐 Overview
- This project is a personal blogging platform where users can:
    Read blog posts
    Explore different topics and categories
    Learn more about the author
    Connect through social links
    Experience a responsive and user-friendly interface across devices
    The website is designed with simplicity, readability, and performance in mind.

  ---

  
## ✨ Features
- Responsive design for mobile, tablet, and desktop
- Clean and modern UI
- Blog listing page
- Individual blog post pages
- About section
- Contact / social media links
- Fast loading performance
- Easy-to-maintain project structure
